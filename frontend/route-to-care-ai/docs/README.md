# Project documentation

These documents capture CarePath Navigator as it evolved from an early proposal into a hospital wait-time prediction prototype.

## Documents

- [`project-proposal.md`](project-proposal.md) — original problem framing and proposed solution
- [`requirements-specification.md`](requirements-specification.md) — functional and non-functional requirements
- [`system-architecture.md`](system-architecture.md) — architecture decisions and planned deployment
- [`system-design.md`](system-design.md) — component and interface design
- [`project-log.md`](project-log.md) — team activity and project milestones
- [`architecture.md`](architecture.md) — annotated gallery of system and UML diagrams

## Scope note

Several documents reference UK or NHS data because this was an early research direction and an ideal future integration. The team's final reported XGBoost evaluation used Hong Kong public hospital data. Some planned features and architecture components were not implemented in the deployed prototype.
