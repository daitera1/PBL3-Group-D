# Legacy data-source exploration

`nhs_scraper.py` is an early experiment for collecting information from NHS pages. It is retained to show the team's data-source exploration, but it was not the source of the final model results.

The final evaluation reported by the team used Hong Kong public hospital data. This script may also require maintenance because public-page structures change over time. Respect the source site's terms, robots policy, privacy requirements, and rate limits before running it.
