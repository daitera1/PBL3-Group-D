# CarePath Navigator — AI-Powered Hospital Wait-Time Prediction

A team-developed healthcare decision-support prototype that combines machine learning predictions with hospital comparison and navigation.

Our XGBoost model achieved a reported mean absolute error of 5.93 minutes and an R² score of 0.8105 on held-out Hong Kong hospital waiting-time data.

**Explore the project:**

- [Working Web Prototype](https://route-to-care-ai.lovable.app)
- [Frontend Source Code](https://github.com/daitera1/PBL3-Group-D/tree/add-carepath-frontend/frontend/route-to-care-ai)
- [Project Documentation](https://daitera1.github.io/PBL3-Group-D/)

The frontend demonstrates the hospital-comparison experience using prepared model outputs. Live model inference is not included in this repository.
