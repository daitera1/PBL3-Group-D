## Running the Frontend Locally

### Prerequisites

- Node.js and npm
- Git

### Installation

**1. Clone the frontend branch**

```bash
git clone -b add-carepath-frontend https://github.com/daitera1/PBL3-Group-D.git
```

**2. Navigate to the frontend directory**

```bash
cd PBL3-Group-D/frontend/route-to-care-ai
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the application**

Open the local URL displayed in your terminal.

### Other Commands

```bash
npm run build
npm run preview
npm run lint
```
